# STRATEGY ASSISTANT — AI providers

AI uses Bring Your Own Key (BYOK). Users add their own API key in the app's AI Control Panel. Requests are sent directly from the device to the chosen provider; no Strategy Assistant AI server or shared API key is required.

Supported adapters: Gemini, OpenAI, Anthropic, OpenRouter, and custom OpenAI-compatible HTTPS endpoints.

Keys are encrypted with AES-GCM and a non-exportable Android Keystore key. Users remain responsible for their provider's billing, quotas, terms, and privacy policy. Never share API keys or include them in screenshots, logs, backups, or source control.
